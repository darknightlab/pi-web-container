# Instructions

- Don't reinvent the wheel. Make good use of the internet. Before thinking or doing something complex yourself, search on the internet first.
- Do not casually run `find /`, network-dependent commands, or other commands that may block for a long time. When necessary, add a timeout, or run the command in a background tmux session and use separate commands to monitor whether it is progressing normally.
- Be especially careful when running any command that could damage the computer system, including accidentally deleting files, filling the disk, exhausting memory, or disrupting the network.
